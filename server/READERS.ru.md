# Личные учётные записи читателей

Для первой группы коллег используется отдельная роль `Коллеги — чтение`:
просмотр опубликованных полок, книг, глав и страниц, поиск и экспорт.
Прав записи, удаления, управления, API и просмотра всех ревизий у роли нет.
Доступ распространяется на опубликованное содержимое согласно действующим
разрешениям книг/страниц. Новые ограничения содержимого нужно проверять отдельно.
Не назначать дополнительные роли, расширяющие права, без согласования.

`scripts/provision-readers.php` использует штатные службы BookStack, принимает
имена, email, случайные стартовые пароли и email администратора из защищённого
JSON через стандартный ввод. Без `--apply` выполняет только предварительную
проверку. При применении создаёт роль/недостающие учётные записи в транзакции,
записывает активность и проверяет суммарные права и запрет записи на всех
текущих объектах. Существующие отличающиеся учётные записи не перезаписывает.
Ядро BookStack не изменяется. На время запуска скрипт и `scripts/lib/agent-access.php`
можно разместить в закрытой временной папке контейнера приложения с сохранением
относительного пути `lib/agent-access.php`. В образе скриптов может не быть.

`scripts/check-colleague-access.py` проверяет реальные входы по HTTPS, чтение,
поиск, экспорт и запрет форм создания/редактирования/удаления/управления.
Для проверки 403 использует `Accept: application/json`: обычный интерфейс
BookStack перенаправляет отказ на главную страницу с уведомлением.
Запросы изменения настоящих статей не выполняются. Тестовые сеансы завершаются.
Учётные данные и отчёты проверки находятся вне Git, в закрытой папке
`../.server-access/colleagues/`. Они не должны попадать в публичный репозиторий.

Для ручной передачи каждому человеку подготовлен отдельный файл с его доступом.
Стартерный пароль следует сменить в настройках своего аккаунта после первого
входа; принудительная смена не настроена. Письма из базы пока не отправляются.
После смены паролей первоначальные значения из файлов больше не подойдут.

Личные учётные записи не предназначены для ботов. Каждому независимому агенту
нужны отдельная учётная запись и ключ с правами чтения, чтобы отключение бота
не отключало коллегу и действия различались в журнале. Внешний MCP на этом
этапе не развёрнут. Ссылки на Google Drive не предоставляют разрешений Drive.
