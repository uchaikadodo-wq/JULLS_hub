Обновления ограничены этими пятью пакетами в существующих совместимых диапазонах.
Не выполнялся `npm audit fix --force`, откат Jest на старую major-версию или

Свежий исходный npm-аудит показывал 10 предупреждений: 2 critical, 2 high,
6 low по классификации npm. После исправлений critical/high отсутствуют.
`npm audit --omit=dev` показывает 0. PHP-аудит исходного lock-файла обнаружил
предупреждение Symfony MIME; аудит исправленного lock-файла — 0 advisories.
Чистый результат означает отсутствие записей в проверенной базе предупреждений
на дату проверки, а не доказательство отсутствия любых уязвимостей.

## Неисправленное предупреждение в инструментах тестирования

В полном npm-дереве остаются **6 low**: одна уязвимость `deepmerge`, отображаемая
также через цепочку Jest/ts-jest. По [публикации об уязвимости](https://github.com/advisories/GHSA-gcqx-w48m-w2h4)
исправленной версии пока нет. Эта библиотека и тестовые инструменты отсутствуют
в конечных app/web-образах. Их исключение из рабочего образа и запуск тестов
без сети не исправляют саму уязвимость. Не передавать этим инструментам
недоверенные конфигурации/входные проекты; пересмотреть при появлении исправления.
