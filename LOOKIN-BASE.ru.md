# Lookin.Team Base

Корпоративная база знаний на BookStack. Этот репозиторий хранит исходники,
оформление, конфигурацию без секретов и скрипты обслуживания.
Статьи, вложения, пароли, токены и резервные копии сюда не входят.

База BookStack: официальный тег `v26.09.2`, commit
`6265d5667dd6904b7aa0d05a8c60795cf104011b`.
Исходники upstream сохранены; дополнения проекта находятся отдельно.
Лицензия BookStack и уведомления о лицензиях сохранены в репозитории.

## Работа с кодом

- Локальная разработка: `compose.local.yaml`, инструкции в `local-dev/README.ru.md`.
- Сервер: `server/compose.yaml`, инструкции в `server/README.ru.md`.
- Фактически проверенное состояние: `local-dev/DEPLOYED.ru.md`.
- Резервные копии и ограничения текущего этапа: `server/BACKUPS.ru.md`.
- Права агентов и локальный MCP: `local-dev/AGENT-ACCESS.ru.md`, `mcp/README.ru.md`.
- Известные ограничения безопасности: `server/dependencies/SECURITY.ru.md`.

Официальный upstream остаётся в Git remote `origin`.
Репозиторий проекта: https://github.com/uchaikadodo-wq/JULLS_hub,
для него используется отдельный remote `company`.
Само добавление remote не означает, что код уже отправлен.

Сначала изменить и проверить код локально, затем отправить согласованный коммит
в репозиторий. Обновление сайта — отдельное действие: снимок данных, сборка
для архитектуры VPS, проверки, установка версии, проверка входа и содержимого.
Автоматический деплой из GitHub пока не настроен. Отправка кода в GitHub сама
по себе не меняет работающую базу и не переносит статьи.

Не запускать upstream `docker-compose.yml` вместо конфигурации проекта.
Не заменять production APP_KEY при восстановлении существующей базы.
Откат кода не откатывает структуру и содержимое БД.
