# Главная Lookin.Team Base — первый вариант

Референс: предоставленный пользователем скриншот базы Додо ИС.

Вариант реализован отдельным переопределением `home/default.blade.php`, без изменения ядра BookStack. Он применяется к главной типа «По умолчанию». С 27.10.2026 для авторизованных внутренних страниц также подключены общая оболочка и оформление; см. раздел ниже.

- Крупный поиск — штатный GET `/search?term=…`, права проверяет BookStack.
- Направления HR, маркетинг, IT, операции, финансы, развитие — предварительные ссылки на тематический поиск. Книги/полки с этими названиями пока не создавались.
- Карточки и фильтры ленты демонстрационные, это не новости компании. Реальных вызовов API/MCP Lookin.Team и фоновых синхронизаций нет.
- Нет блока поддержки. Есть ссылки на материалы, избранное, профиль и учётную запись; настройки показываются только при соответствующем праве.
- Все ресурсы локальные: нет внешних шрифтов, изображений, аналитики или новых npm-зависимостей.
- На экране шире 760px меню находится слева, в узком — сверху.

## Файлы и подключение

Содержимое `local-dev/theme/` монтируется read-only в `/app/themes/lookin-base` через `compose.local.yaml`. `.env` и `local-dev/env.example` содержат `APP_THEME=lookin-base`. Пример `.env` не содержит реальных секретов; существующий APP_KEY не менялся.

Редактирование шаблона, CSS и JS выполняется в этой папке через Codex. После изменения CSS/JS увеличивайте `?v=` в шаблоне, поскольку theme assets кэшируются браузером.

Если `docker` не найден: `export PATH="/Applications/Docker.app/Contents/Resources/bin:$PATH"`.

```sh
# После изменения APP_THEME / Compose:
docker compose -f compose.local.yaml up -d app web
docker compose -f compose.local.yaml exec -T app php artisan view:clear
# Проверки запуска и входа:
python3 local-dev/check-runtime.py
python3 local-dev/check-http.py
```

Чтобы отключить тему: удалите только строку `APP_THEME=lookin-base` из локальной `.env`, пересоздайте app указанной командой и очистите views. Данные базы и исходники от этого не меняются. Не выполняйте `down --volumes`.

## Проверено

Compose config и статические ограничения — PASS. Контейнеры/вход HTTP — PASS после подключения темы. В браузере проверены отображение главной, реальный переход в поиск «отпуск» и переключение фильтра «Обновления базы». На пустой базе поиск ожидаемо возвращает 0 результатов. Исправлено начальное отображение inline Blade-директивы; на итоговой странице её текста нет.

UI-проверка пока выполнена в узком окне встроенного браузера; широкая раскладка задана CSS, но отдельная визуальная проверка широкого viewport ещё не выполнена. Полный PHPUnit не запускался для изменения оформления. Тема требует повторной проверки при обновлении BookStack.

Изменены/созданы: compose.local.yaml, локальная ignored .env (только APP_THEME), local-dev/env.example, home/default.blade.php, public/lookin.css, public/lookin.js и этот README. Сохранены theme-startup.log, theme-verification.json и снимки интерфейса; обновлены runtime-checks.json/http-checks.json и FILES.txt.

## Внутренние страницы, 27.10.2026

По поручению пользователя оформление распространено на профиль, поиск, списки материалов, полки, избранное и настройки учётной записи. Утверждённая главная и её lookin.css сохранены побитово без изменений. Новый interior.css подключается только во внутренней оболочке для авторизованных пользователей; на главной его нет. Права, пользователи, пароли и содержимое не изменялись.

Новые переопределения темы:
- `layouts/base.blade.php`: копия upstream-шаблона зафиксированной версии с условной оболочкой, общей навигацией и штатными search/dropdown компонентами. Стек JS/CSP/CSRF/уведомления сохранён.
- `lookin/sidebar.blade.php`: отдельное меню для внутренних страниц с направлениями, книгами, полками, избранным, профилем и настройками при наличии прав.
- `users/profile.blade.php`: оформление существующих данных профиля; сохраняются загруженный аватар, счётчики, доступные материалы и штатная история действий.
- `users/account/layout.blade.php`: компактная навигация вкладок; сами формы/поля/обработчики остаются штатными.
- `search/all.blade.php`: штатная форма фильтров в раскрывающемся блоке, результаты перед фильтрами. Query processing и проверка прав не менялись.
- `public/interior.css`: scoped стили, Prata, карточки, цвета, навигация, адаптация узкого окна. Cache version 8.

Проверено в браузере: профиль, редактирование профиля (без отправки формы), поиск из верхней панели, раскрытие фильтров, книги, полки, избранное, чтение настроек, форма создания книги (без сохранения), открытие меню аккаунта и закрытие Escape, возврат на неизменённую главную. Выполнена визуальная проверка профиля в среднем и узком окне, поиска и списка книг в узком окне. Исправлены конфликт штатных mobile-header стилей с меню аккаунта, слишком узкая область имени пользователя и контраст текста кнопки.

Ограничения: страницы существующих книг/глав/статей и полноценный редактор статьи ещё не проверены на наполненной базе — тестовых материалов пока нет. Для редактора предусмотрено сохранение full-height flex layout. Dark mode отдельно не проверен. Полный PHPUnit для этой правки оформления не запускался. Общая оболочка задаёт стиль всем шаблонам на layouts.base, но специализированные экраны могут требовать дальнейшей визуальной настройки после наполнения.

Результаты: `local-dev/interior-verification.json`. Снимки: `local-dev/lookin-profile-preview.png`, `local-dev/lookin-search-preview.png`. Все изменения в теме; upstream tracked sources по git diff остались без правок. Новые зависимости и внешние ресурсы не добавлялись. Для обновления BookStack особенно важно сравнить переопределённый base с новой upstream-версией и проверить формы/редактор.

Откат всего оформления: убрать APP_THEME из локальной .env и пересоздать app с очисткой views (см. выше). Чтобы убрать только оформление внутренних страниц с сохранением главной, предварительно сохранить копии и убрать из активной темы перечисленные переопределения layouts/base, users/profile, users/account/layout и search/all; общий CSS и sidebar без этих переопределений не подключаются. Не менять БД и не удалять Docker volumes.
